Sankova UKB

Sankova UKB é uma plataforma desenvolvida com o objetivo de facilitar a transição dos estudantes do ensino médio para o ensino superior em Angola.

A plataforma reúne informações sobre universidades, institutos superiores, faculdades, cursos e disciplinas de acesso, permitindo que estudantes encontrem informações sobre diferentes opções de formação e se preparem para os exames de admissão por meio de **testes simulados online.

Além do módulo de preparação para os exames, o Sankova UKAB possui um módulo independente de sugestão de cursos, que utiliza Inteligência Artificial para recomendar cursos com base nos interesses, habilidades e áreas de atuação indicadas pelo estudante.



🎯 Objetivo

O principal objetivo do Sankova UKAB é tornar o processo de escolha e preparação para o ingresso no ensino superior mais acessível e organizado para os estudantes angolanos.

A plataforma procura centralizar informações que normalmente estão distribuídas entre diferentes fontes e oferecer aos estudantes um ambiente onde possam:

* Conhecer universidades e institutos superiores;
* Consultar faculdades e cursos disponíveis;
* Conhecer as disciplinas relacionadas aos exames de admissão;
* Consultar os tópicos que devem ser estudados;
* Realizar testes simulados;
* Preparar-se para os exames de admissão;
* Explorar possibilidades de cursos de acordo com seus interesses e habilidades.

Na prática, o Sankova UKAB funciona como uma espécie de **preparatório online para o ingresso no ensino superior**.



🚀 Principais funcionalidades

🏛️ Universidades e Institutos Superiores

O sistema permite cadastrar e administrar diferentes instituições de ensino superior de Angola.

Para cada instituição podem ser cadastradas informações relacionadas à sua estrutura acadêmica.

A plataforma pode reunir:

* Universidades;
* Institutos superiores;
* Faculdades;
* Cursos;
* Disciplinas;
* Tópicos de estudo;
* Conteúdos relacionados aos exames de admissão.



🎓 Faculdades

Cada universidade pode possuir diferentes faculdades.

Cada faculdade possui sua própria administração, permitindo gerenciar as informações relacionadas àquela unidade acadêmica.

A estrutura pode ser representada da seguinte forma:

```
Universidade
│
├── Faculdade 1
│   ├── Curso 1
│   ├── Curso 2
│   └── Curso 3
│
├── Faculdade 2
│   ├── Curso 4
│   └── Curso 5
│
└── Faculdade 3
    ├── Curso 6
    └── Curso 7
```


📚 Cursos

Cada faculdade pode possuir diversos cursos.

Os cursos possuem informações próprias e estão associados às disciplinas que normalmente fazem parte da preparação para os exames de admissão.

Para cada curso podem ser definidos:

* Disciplinas;
* Tópicos de estudo;
* Conteúdos para preparação;
* Questões;
* Testes simulados.


📖 Disciplinas

Cada curso possui disciplinas relacionadas ao processo de preparação para o exame de admissão.

As disciplinas organizam os conteúdos que o estudante deverá estudar.

Por exemplo:

```
Curso
│
├── Matemática
│   ├── Álgebra
│   ├── Funções
│   └── Geometria
│
├── Física
│   ├── Mecânica
│   ├── Eletricidade
│   └── Ondas
│
└── Português
    ├── Gramática
    ├── Interpretação de texto
    └── Literatura
```



📝 Testes simulados

Uma das principais funcionalidades do Sankova UKAB é a possibilidade de realizar testes simulados online.

Os simulados são preparados com questões relacionadas às disciplinas e aos conteúdos que fazem parte da preparação para os exames de admissão.

O estudante pode acessar um curso, consultar as disciplinas e realizar testes simulados para testar seus conhecimentos.

O objetivo é proporcionar uma experiência de preparação antes da realização do exame de admissão.

### Fluxo do estudante

```

    ▼

    │
    ▼

    │
    ▼
Escolhe um curso
    │
    ▼
Consulta as disciplinas
    │
    ▼
Estuda os tópicos
    │
    ▼
Realiza testes simulados
    │
    ▼
Prepara-se para o exame de admissão
```



📚 Tópicos de estudo

Cada disciplina pode possuir diferentes tópicos.

Os tópicos representam os conteúdos que o estudante deve estudar para se preparar para determinada disciplina relacionada ao exame de admissão.

Essa organização permite que o estudante tenha uma visão mais clara do que precisa estudar.

```
Disciplina
│
├── Tópico 1
├── Tópico 2
├── Tópico 3
└── Tópico 4
```



🤖 Sugestão de cursos com Inteligência Artificial

O Sankova UKB possui também um módulo independente de sugestão de cursos.

Esse módulo não depende da universidade escolhida pelo estudante.

O estudante pode acessar a funcionalidade sem necessariamente estar cadastrado na plataforma e informar:

* Seus interesses;
* Suas habilidades;
* Áreas de atuação de interesse.

Com base nessas informações, o sistema utiliza **Inteligência Artificial** para sugerir **três cursos** que podem estar relacionados ao perfil informado.

### Fluxo

```
Interesses
     +
Habilidades
     +
Áreas de atuação
     │
     ▼
Inteligência Artificial
     │
     ▼
3 sugestões de cursos
```

O objetivo dessa funcionalidade é ajudar estudantes que ainda não sabem qual curso escolher a explorar possibilidades de formação alinhadas aos seus interesses e habilidades.



👥 Perfis de acesso

O sistema possui uma estrutura hierárquica de administração.

👑 Administrador Geral

É o administrador responsável pela administração geral da plataforma.

Possui permissões para gerenciar os principais elementos do sistema, incluindo:

* Universidades;
* Institutos superiores;
* Estruturas acadêmicas;
* Administradores;
* Configurações gerais;
* Demais recursos administrativos da plataforma.


🏛️ Administrador da Universidade

Cada universidade pode possuir uma administração própria.

O administrador da universidade gerencia informações relacionadas à instituição como um todo.

Suas responsabilidades estão relacionadas à administração geral daquela universidade, sem interferir diretamente em recursos que pertencem exclusivamente a outras universidades.


🎓 Administrador da Faculdade

Cada faculdade pode possuir seus próprios administradores.

O administrador da faculdade é responsável pelos recursos relacionados à sua faculdade, podendo gerenciar informações e elementos acadêmicos pertencentes àquela unidade.


📚 Administrador do Curso

Cada curso pode possuir administradores responsáveis pela sua gestão.

O administrador do curso pode gerenciar os elementos diretamente relacionados ao curso, incluindo:

* Informações do curso;
* Disciplinas;
* Tópicos;
* Questões;
* Testes simulados;
* Conteúdos relacionados à preparação.

A estrutura de permissões segue uma lógica hierárquica:

```
Administrador Geral
        │
        ▼
Administrador da Universidade
        │
        ▼
Administrador da Faculdade
        │
        ▼
Administrador do Curso
        │
        ├── Disciplinas
        │
        ├── Tópicos
        │
        ├── Questões
        │
        └── Testes Simulados
```

Cada nível possui responsabilidades e permissões relacionadas ao seu respectivo âmbito de administração.



🏗️ Arquitetura

O projeto foi desenvolvido utilizando o padrão arquitetural **MVC — Model, View, Controller**, disponibilizado pelo Laravel.

### Model

Responsável pela representação e manipulação dos dados da aplicação.

### View

Responsável pela apresentação das informações e pela interface utilizada pelos usuários.

### Controller

Responsável por intermediar as requisições, aplicar as regras necessárias e conectar os Models às Views.

A estrutura segue o conceito:

```
Usuário
   │
   ▼
Controller
   │
   ├──────────► Model
   │              │
   │              ▼
   │           Banco de Dados
   │
   ▼
View
   │
   ▼
Usuário
```

# 📥 Instalação

## 1. Clonar o repositório

```bash
git clone https://github.com/SEU_USUARIO/sankova-ukab.git
```

Entre na pasta:

```bash
cd sankova-ukab
```


## 2. Instalar as dependências do PHP

Execute:

```bash
composer install
```


## 3. Instalar as dependências do frontend

```bash
npm install
```


## 4. Criar o arquivo `.env`

Copie o arquivo de configuração:

```bash
cp .env.example .env
```

No Windows, caso o comando acima não funcione, você pode utilizar:

```powershell
copy .env.example .env
```

Depois configure no `.env` as informações do banco de dados utilizado pelo projeto.

Exemplo:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ukbstore
DB_USERNAME=root
DB_PASSWORD=
```


5. Gerar a chave da aplicação

```bash
php artisan key:generate
```



6. Executar as migrations

Depois de configurar o banco de dados:

```bash
php artisan migrate
```

As migrations irão criar as tabelas necessárias para o funcionamento da aplicação.


7. Popular o banco de dados

Execute os seeders:

```bash
php artisan db:seed
```

Os seeders são responsáveis por inserir os dados iniciais definidos pelo projeto.

> Caso o projeto possua um `DatabaseSeeder` configurado para executar os demais seeders, o comando acima será suficiente.



8. Compilar os recursos do frontend

Execute:

```bash
npm run dev
```

Para desenvolvimento, mantenha esse comando em execução enquanto trabalha no projeto.



9. Iniciar o servidor Laravel

Em outro terminal:

```bash
php artisan serve
```

Por padrão, a aplicação ficará disponível em:

```text
http://127.0.0.1:8000
```
